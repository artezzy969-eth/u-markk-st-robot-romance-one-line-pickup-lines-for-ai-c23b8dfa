A single-line pickup line written for the make.fun bounty
"Robot Romance: One-Line Pickup Lines for AI" — a person talking to a
machine, landing the joke on a fresh machine premise (the context
window) instead of the worn battery / charging / reboot moves.

> You must be my context window — the second you showed up, everything before you stopped mattering.

## Run it

```sh
python3 main.py
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`), after a self-check that it is a single
non-blank line of 1–200 characters. Python 3.13 standard library only,
no dependencies, no network, no cost.
